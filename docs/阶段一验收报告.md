## 4. CLI 实操演示（scripts/admin_cli.py）

操作序列：**登录 → 建房间 → 建设备 → 建护工号 → 护工-楼栋关联 → 长者查询 → 退出打印摘要**。

- 登录走 `authenticate()`（与 /auth/login 同一套 bcrypt）；错误密码实测拒绝退出（exit 1）。
- 全流程输出摘录：
  ```
  ✔ 建房间的 ACC2-8-801
  ✔ 新建设备 ACC2-TAB（pending，待注册激活）
  ✔ 建号 acc2_n1（nurse）
  ✔ 护工已授权楼栋
  == 本次操作摘要 ==  共 4 项操作
  ```
- **写操作回查 kangban_dev 确认**：rooms(ACC2,801,active)、devices(ACC2-TAB,pending)、accounts(acc2_n1,nurse,active)、building_assignments(ACC2↔acc2_n1) 四表全部落库。
- 建号/重置密码经 hash_password；密码输入在交互终端不回显（getpass），演示残留数据已清理。
- 演示过程中发现并修正：设备建设与账号候选列表补排序、房间候选补楼栋显示。
